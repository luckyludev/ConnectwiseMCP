ConnectWise MCP v2 Architecture

Stateless MCP 2026-07-28 • Microsoft Entra • Cloudflare Worker • per-user ConnectWise security

Identity and access

  • One Entra group gates application access
  • Validated tid:oid selects the exact profile
  • Names and unverified email are never authorization keys

ConnectWise permissions

  • One API member per team member when practical
  • ConnectWise Security Role remains final enforcement
  • No shared administrator fallback

Lean deployment

  • Single stateless TypeScript Worker
  • No Docker, tunnel, proxy, database, or admin UI
  • Current Docker stack retained during migration

Security posture

  • Secrets selected only by verified server-side identity
  • Request-scoped clients prevent cross-user leakage
  • Unmapped, ambiguous, or incomplete profiles fail closed
